<hr>

<h3>Ementa</h3>
<p align="justify">
  A disciplina de Arquitetura de Banco de Dados é destinada a estudantes dos cursos de computação. O estudante analisa um problema de armazenamento de dados e representa a solução em modelos conceitual, lógico e físico. Ele cria ou atualiza o banco de dados, utilizando estratégias para inserir, alterar, excluir e recuperar dados. O estudante cria modelos a partir de coleções de dados, usando engenharia reversa. Ao final, o estudante é capaz de criar bancos de dados que permitam a recuperação dos dados armazenados e solucionem o problema da área de aplicação.
</p>
